# Code of Conduct

Everyone is welcome to contribute to Relay. This code applies to project issues, pull requests, reviews, and other project spaces. It also applies when someone represents the project elsewhere.

## Expected behavior

- Treat people with respect, regardless of identity, background, or experience.
- Discuss ideas and code with specific, useful feedback.
- Accept corrections and give others room to learn.
- Respect privacy and consent. Share another person's information only with permission.

Harassment, discrimination, threats, sexual harassment, personal attacks, deliberate disruption, spam, and publication of private information are not acceptable. Retaliation against a person who makes a report is also not acceptable.

## Report a concern

Use GitHub's **Report content** option on the affected issue, pull request, or comment. Where available, choose **Report to repository admins**. For a platform abuse report, choose **Report abuse to GitHub Support**. See [GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).

Include links and enough context to explain the concern. Avoid repeating private information in public. If the concern involves the repository owner, report it directly to GitHub Support. Use [SECURITY.md](SECURITY.md) for software vulnerabilities.

## Enforcement

The repository owner handles reports received by the project. GitHub handles reports sent to GitHub Support. Depending on the behavior and its impact, the owner may request a correction, remove content, give a warning, or restrict participation temporarily or permanently. Serious threats or harassment can result in an immediate restriction.

The owner will consider context and explain project moderation decisions where possible without exposing private information. A person affected by a decision may request reconsideration through the original reporting channel if that channel supports replies.
